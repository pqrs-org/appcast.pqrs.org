- 🔔 Important Notes
    - After upgrading, enable `Karabiner-Elements Privileged Daemons v3` under Background App Activity in System Settings.
- 💥 Breaking Changes
    - Moved `karabiner_cli` from `/Library/Application Support/org.pqrs/Karabiner-Elements/bin/karabiner_cli` to `/Applications/Karabiner-Elements.app/Contents/Helpers/karabiner_cli`.
    - Moved bundled helper apps into `/Applications/Karabiner-Elements.app/Contents/Helpers`.
    - Moved maintenance scripts into `/Applications/Karabiner-Elements.app/Contents/Resources`.
- ✨ New Features
    - Added Japanese localization.
    - Added [`mouse_motion_and_wheel_to_key`](https://karabiner-elements.pqrs.org/docs/json/complex-modifications-manipulator-definition/other-types/mouse-motion-and-wheel-to-key/) (Thanks to @BenjaminVanRyseghem)
    - Added `system.ui_language` to variables.
    - Added `set_caps_lock_led` to complex modifications, which allows the caps lock LED to be turned on or off independently of the caps lock state. (Thanks to @anandghegde)
- 🐛 Bug Fixes
    - Fixed an issue where Caps Lock events generated by key remapping were remapped again when CGEventTap fallback was enabled.
    - Fixed an issue where ISO layout-specific keys (e.g., `` `~ `` / `§±` / `^°` / `²` ↔ `\|` / `<>`, depending on the layout) could produce the wrong characters when CGEventTap fallback was enabled.
- ⚡️ Improvements
    - Improved text and other UI elements for macOS 27.
    - Changed inter-process communication between Karabiner-Elements processes from UNIX domain sockets to XPC.
    - Fixed an issue where selection indicators in the Simple Modifications key picker were not displayed on macOS 27.
    - EventViewer now displays caps lock LED state changes with an appropriate name instead of "Unsupported HID usage".
    - Add `Show confirmation submenu for Quit Karabiner-Elements` configuration.
    - JavaScript-based Complex Modifications rules are no longer evaluated while disabled.
    - Limited the maximum size of `karabiner.json` to 64 MB.
    - Limited JavaScript `console.log` output to 1 MB.
